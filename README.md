# ATTiny Binary Counter PCB Project
A simple binary counter that uses an ATTiny to keep count. Features include automatic counting via internal clock, and a reset button.

This Project was created for Hack Club 8-Pin Grant!

Link: https://8-pin-grant.hackclub.com/
