# ATTiny 4x5 LED Matrix PCB Project
A 4x5 LED Matrix that can light up in pre-programmed sequences or display simple symbols or images.

This Project was created for Hack Club 8-Pin Grant!

Link: https://8-pin-grant.hackclub.com/
